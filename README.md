# mgs-mode: Emacs Major Mode for MGS Programming Language

This is the emacs mode designed to provide emacs support for the MGS programming language.

As the language is still in active development, so is this mode, meaning there may be some
bugs and inconsistencies. If you spot anything that doesn't seem right, please raise a
issue for this and we will look into it.

Currently, this mode only provides basic syntax highlighting.
